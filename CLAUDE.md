# plainsailapps.com

Public GitHub Pages site for all Plainsail apps (privacy and support pages). Custom domain plainsailapps.com, DNS at GoDaddy (4 A records to GitHub Pages, www CNAME to plainsail-apps.github.io).

- This is the ONLY site for plainsailapps.com. Do not create another Pages site or point the domain elsewhere.
- Every page is generated by `python3 scripts/build.py`: the home page, an app page per app at /<slug>/, and /<slug>/privacy and /<slug>/support. style.css is hand-edited. The text inside <main> of privacy.html and support.html is hand-edited; the build re-wraps it in the shared header and footer.
- Screenshots and icons live in assets/<slug>/ (screen-1..4.webp, icon.webp). An app with no shots shows a placeholder.
- Per-app pages: /<slug>/privacy and /<slug>/support, generated by `python3 scripts/build.py` from the APPS list there. To add an app, add an entry to APPS, run the script, commit, push.
- Slugs in use: aigovernanceprep, rentreceiptbook, jobsheetpad, chorejar, fermata, financekids (its privacy page is hand-written in financekids/privacy.html because it is the one app with a server; privacy_custom=True re-wraps it).
- Publisher name is PUBLISHER in scripts/build.py and in the footer of the shared pages (Compora Pte. Ltd. until the rename to Plainsail Pte. Ltd.).
