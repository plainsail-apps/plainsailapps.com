# plainsailapps.com

Public GitHub Pages site for all Plainsail apps (privacy and support pages). Custom domain plainsailapps.com, DNS at GoDaddy (4 A records to GitHub Pages, www CNAME to plainsail-apps.github.io).

- This is the ONLY site for plainsailapps.com. Do not create another Pages site or point the domain elsewhere.
- Shared pages: index.html, privacy.html, support.html, style.css (hand-edited).
- Per-app pages: /<slug>/privacy and /<slug>/support, generated by `python3 scripts/build.py` from the APPS list there. To add an app, add an entry to APPS, run the script, commit, push.
- Slugs in use: aigovernanceprep, rentreceiptbook, jobsheetpad.
- Publisher name is PUBLISHER in scripts/build.py and in the footer of the shared pages (Compora Pte. Ltd. until the rename to Plainsail Pte. Ltd.).
